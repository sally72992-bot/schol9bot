# Бот школьного расписания

## Возможности
- Расписание на сегодня и завтра
- Ближайший урок
- Время звонков
- Напоминания за 10 и за 5 минут до каждого урока
- Учебные дни: понедельник–пятница

## Запуск локально
1. Установи Python 3.11 или новее.
2. Установи зависимости:
   `pip install -r requirements.txt`
3. Создай переменную окружения `TELEGRAM_BOT_TOKEN` с токеном от BotFather.
4. Запусти:
   `python bott.py`

## Развёртывание на FadeHost
- Если есть поле Root Directory, укажи папку, где лежат `bott.py` и `requirements.txt`.
- Install command: `pip install -r requirements.txt`
- Start command: `python bott.py`
- Environment Variables:
  - `TELEGRAM_BOT_TOKEN` = токен бота от BotFather
  - `TIMEZONE` = `Asia/Tashkent` (можно не задавать, это значение по умолчанию)

Важно: если бесплатный хостинг останавливает или «усыпляет» процесс, напоминания во время остановки приходить не будут. Для работы напоминаний бот должен постоянно работать.

## Файлы данных
Бот создаёт `subscribers.json` и `sent_reminders.json` рядом с программой. Если хостинг удаляет файлы при перезапуске/переразмещении, список подписчиков может сброситься — просто отправь боту `/start` снова.

## Расписание
Предметы и время уроков находятся в начале файла `bott.py`, в словаре `WEEKDAYS`.
